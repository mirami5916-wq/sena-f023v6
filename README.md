# Sistema Centralizado F023V6 - SENA

Aplicación web compilada en HTML / CSS / JS lista para producción o despliegue en **GitHub Pages**.

## Estructura de esta carpeta:
- `index.html`: Punto de entrada principal de la aplicación.
- `assets/`: Estilos CSS y código JavaScript empaquetado y optimizado con conexión automática a Supabase.
- `MANUAL_DE_USUARIO_SENA_F023V6.pdf`: Manual de usuario y operación oficial descargable.

## Cómo publicarlo en GitHub Pages:
1. Crea un repositorio nuevo en GitHub (por ejemplo `sena-f023v6`).
2. Sube todos los archivos de esta carpeta (`index.html`, carpeta `assets/`, etc.) a la rama principal (`main`).
3. Ve a **Settings** > **Pages** en tu repositorio de GitHub.
4. En **Branch**, selecciona `main` y la carpeta `/ (root)`, luego haz clic en **Save**.
5. ¡Listo! Tu aplicación quedará publicada en internet con su enlace público en GitHub.
